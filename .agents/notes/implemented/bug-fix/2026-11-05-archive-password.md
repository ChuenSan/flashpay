# Agent Note: 压缩包密码随资源交付

Status: implemented

## Problem

赞助确认卡片仅提供下载链接，后台没有压缩包密码配置，用户取得资源后缺少解压信息。

## Decision

`SiteSetting.archivePassword` 与下载链接共同保存、读取和交付。确认、重放及浏览器恢复使用当前配置；公开页面初始响应和赞助名单不返回密码。密码原样保存，空字符串表示不展示密码；旧版仅提交链接的设置请求保留已有密码。

## Alternatives considered

将密码写入下载链接可复用现有字段，但网盘提取码与解压密码用途不同，无法独立配置和复制。单独读取两个字段便于局部改动，但配置更新期间可能组合出不匹配的链接和密码，因此使用同一次读取。

## Consequences

新增迁移只添加默认空值的列，保留原设置和记录。上线须先执行数据库迁移并重新生成 Prisma Client。后台可清空密码；已打开的页面刷新后取得新配置。

验证覆盖后台鉴权、保存、非法输入不写入、进程重启持久化、确认重放和恢复，以及浏览器确认展示、复制、空配置和手机布局。独立测试保留临时数据库，避免运行包含文件删除的既有测试清理。
